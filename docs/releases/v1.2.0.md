v1.2.0 - Streamline

Big files no longer have to fit in memory. December 2025.

### What's new
* New streaming file format (v3): data is encrypted in 64 KB chunks, so multi-gigabyte files like videos or archives work with very little RAM
* More accurate progress bar, based on the real chunks
* Safer finishing of decrypted files, so an interrupted run doesn't lose data

### Fixed
* Freezes and crashes when a file was larger than the free memory
* Leftover temporary files and wrong permissions after a run

> [!WARNING]
> New files use the v3 format and need TimENC 1.2.0 or newer.

### Compatibility
| | |
|---|---|
| Reads | v2, v3 (v2 files are still loaded into memory completely) |
| Writes | v3 |
| Older TimENC versions | Cannot open v3 files |
