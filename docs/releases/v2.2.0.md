v2.2.0 - Smöl

Optional compression before encryption, for smaller `.timenc` files. June 2026.

### What's new
* Compress with zstd before encrypting (`-c` / `--compress`, or the checkbox in the app). It helps most with text, logs, source code and folders.
* New file format v4.5. The compression flag sits in the encrypted metadata, so it can't be changed without detection.
* If decryption fails, the `.timenc` file is kept

### Security
* No change to the encryption itself. Compression can in theory leak the compressed size to an attacker who can repeatedly encrypt chosen data. For encrypting your own files offline that doesn't apply, and compression stays off unless you ask for it.

### Compatibility
| | |
|---|---|
| Reads | v3, v4, v4.5 |
| Writes | v4.5, always |
| Older TimENC versions | Reject v4.5 files with "Unsupported version: 5" instead of producing garbage |
