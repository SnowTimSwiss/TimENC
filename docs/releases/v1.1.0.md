v1.1.0 - Polish

The update checker works properly now and the shortcut settings look better.

### What's new
* Shortcut settings redesigned as a clean, scrollable list

### Fixed
* The update checker never reached GitHub because of a stray space in the URL
* Versions were compared wrongly, so `1.10.0` could be reported as older than `1.2.0`. They are now compared as numbers.
* A rare crash when cancelling tasks quickly
* Shortcut names ignored the selected language

### Compatibility
| | |
|---|---|
| Files | No change, install over the old version and keep your settings |
