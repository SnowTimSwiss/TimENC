v2.1.0 - Safe Heaven

File names and folder flags are now encrypted too.

### What's new
* New file format v4: the metadata (file name, whether it is a folder) is encrypted instead of readable
* Password and keyfile are mixed in as separate inputs
* Stronger Argon2 settings for new files, stored with a version

### Security
* Metadata and data use separate authenticated contexts

### Compatibility
| | |
|---|---|
| Reads | v2, v3, v4 |
| Writes | v4 |
