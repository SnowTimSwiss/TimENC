v2.1.1

Fixes opening v3 files and trims the list of supported formats.

### Fixed
* Files from the original Python version (v3) could not be decrypted. The decryption now matches the Python chunk format again.

### Changed
* v2 decryption was removed. If you still have v2 files, decrypt them with an older version first.

### Compatibility
| Format | Decrypt | Encrypt |
|---|---|---|
| v2 | no | no |
| v3 | yes | no |
| v4 | yes | yes |
