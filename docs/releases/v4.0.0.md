v4.0.0 - Featherweight

A new, much lighter interface. All `.timenc` files stay compatible, in both directions. November 2026.

### What's new
* The window is drawn natively with egui instead of inside an embedded web browser. It opens faster, uses far less memory and no CPU while idle, and the downloads are much smaller (about 12 MB).
* No web engine means much less code that could be attacked
* Passwords are kept in memory that is wiped as soon as they are no longer needed
* The whole window, not just the title bar, follows the system light/dark setting
* Opening a `.timenc` file while TimENC is already open hands it to the open window (Linux)

### Security
* Rewritten documentation, including a section on what is and isn't protected and how to report a problem: [SECURITY.md](https://github.com/SnowTimSwiss/TimENC/blob/main/SECURITY.md)
