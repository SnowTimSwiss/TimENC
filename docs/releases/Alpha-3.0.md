Alpha 3.0

The app now runs on Windows, macOS and Linux, with a new look and configurable shortcuts. December 2025.

> [!WARNING]
> Breaking changes in the app (not the files): the interface is completely redesigned, settings are stored in a new place, and file associations may need to be registered again.

### What's new
* New dark interface with a sidebar, a password strength indicator and better drag & drop
* Keyboard shortcuts you can change, with profiles, conflict detection and a reset button
* Windows installer, macOS app (Intel and Apple Silicon) and a Linux AppImage
* Settings panel with English and German
* Smarter file name suggestions and more accurate progress

### Fixed
* You can now encrypt and decrypt a file in the same session

### Security
* Memory is wiped more thoroughly, keyfile handling improved, extra integrity checks

### Compatibility
| | |
|---|---|
| Files | Unchanged format (v2), existing `.timenc` files keep working |
