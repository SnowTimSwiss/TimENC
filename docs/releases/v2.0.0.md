v2.0.0 - Speeeed

TimENC is rewritten in Rust. March 2026. The Python version is gone, and files from it still open.

### What's new
* New engine in Rust: faster, uses less memory, and the download shrinks from about 100 MB to about 10 MB
* New desktop interface built with Tauri: dark theme, drag & drop, password strength indicator, keyfile generator and progress with status messages
* ChaCha20-Poly1305 in 64 KiB chunks, Argon2id key derivation (4 passes, 128 MB, 4 lanes)
* Protection against path traversal in archives
* Passwords and keys are wiped from memory after use
* Packages: Windows installer and portable `.exe`, macOS `.dmg`, Linux AppImage and `.deb`

### Security
* Header is authenticated, so changes to it are detected

### Compatibility
| | |
|---|---|
| Reads | v2, v3 |
| Writes | v3 |
| Older TimENC versions | Same format as the Python version, keyfiles are compatible (32 bytes) |
