v3.0.0 - Deadbolt

The first cryptographic upgrade since v4: a new file format with stronger integrity guarantees. August 2026.

> [!WARNING]
> New files use format v6 and cannot be opened by TimENC 2.x ("unsupported version"). If you share `.timenc` files, the other person needs 3.0.0 or newer. Everything older still opens.

### What's new
* **Truncation is detected.** Before, a file cut at a chunk boundary decrypted without error and gave you a shorter file. Every chunk now carries its position and a final-chunk marker, and the stream has to end at the final one. Reordered, duplicated, dropped and appended chunks are caught too.
* **One file, one password.** A key commitment in the header means a file can't be crafted to open under two passwords. A wrong password is also rejected right after key derivation.
* **Padding.** `--pad` hides the exact file size (1000 bytes becomes 1024, at most about 12% bigger).
* **Key derivation strength.** `--kdf-profile balanced` (256 MB, 3 passes) or `paranoid` (1 GB, 4 passes), also in the app. The setting is stored in the file.
* Separate keys for metadata, data and commitment, and Argon2 runs once per file instead of twice
* Argon2 settings are read from the header (within 8 MiB to 4 GiB and 1 to 64 passes), so they can be raised later

### Fixed
* Bad input in a header could crash the program. It now returns an error.

### Security
* Details of every change are in the [README](https://github.com/SnowTimSwiss/TimENC#file-format-v6)
* About quantum computers: TimENC has no public-key cryptography, so Shor's algorithm has nothing to attack. Grover cuts the 256-bit key to about 128 bits, which is still far out of reach.

### Known issue
* Compressing with `--compress` wrote a temporary file with the compressed data to disk. Fixed in 3.1.0.
