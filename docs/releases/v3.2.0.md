v3.2.0 - Overdrive

A security review, faster encryption, and a few Linux fixes. November 2026.

### What's new
* Large files and folders encrypt and decrypt up to 2 to 3 times faster, compressed files about 3 times. The file format is unchanged.
* New `.rpm` package (Fedora, openSUSE, and others)
* Double-click and "Open With" on `.timenc` files now work from the DEB, RPM and Flatpak packages
* The title bar follows the system dark mode on GNOME

### Fixed
* Passwords were silently trimmed of spaces at the start and end. A password like `secret ` became `secret`, and the file didn't open from the command line. Files made that way still open.
* Passwords stayed in the window after a successful run. They are cleared now.

### Security
* Keyfiles were created readable by every user on the machine. They are now `0600`.
* A hostile archive (from someone who knows the password) could plant hard links, devices or pipes when extracted. Only files, folders and symlinks are accepted now.
* Keyfiles larger than 16 MiB and empty keyfiles are refused
* Dependencies with known security advisories were updated
* Tests on three platforms, a dependency audit and fuzzing now run in CI. Details and the threat model are in [SECURITY.md](https://github.com/SnowTimSwiss/TimENC/blob/main/SECURITY.md).
