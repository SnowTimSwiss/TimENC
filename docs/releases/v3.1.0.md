v3.1.0 - Belt and Braces

Safer file handling: TimENC no longer deletes things unless you tell it to. September 2026.

### What's new
* Originals are kept by default. Deleting is an option, and only happens after the new file has been checked.
* The password has to be entered twice when encrypting, in the app and in the command line (which now asks for the password instead of needing `-p`)
* Folders and compressed files are no longer written unencrypted to a temporary folder first
* Symbolic links inside folders are stored as links instead of being followed
* Flatpak runtime updated to GNOME 50

### Fixed
* An existing file could be overwritten. It never is now.
* A crash or power loss during encryption could leave a partly written `.timenc` file. It is now written to a temporary file, synced to disk, and only then moved into place.
